# Laowu Meme Forge 1.20.1

这是基于 [Rogic460/Minecraft-laowu-meme](https://github.com/Rogic460/Minecraft-laowu-meme) 修改的 **Minecraft Forge 1.20.1** 版本。

## 修改

- 将原模组移植到 Minecraft 1.20.1
- 将模组加载器适配为 Forge
- 调整部分代码和资源，使其能够在 1.20.1 环境下运行
- 保留原模组的主要音频与触发效果

## 使用方法

1. 安装 Minecraft 1.20.1 Forge
2. 将模组 `.jar` 文件放入游戏的 `mods` 文件夹
3. 启动游戏
